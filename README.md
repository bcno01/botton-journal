# ボタン記録

好きな名前の「ボタン」を作って押すだけで、その瞬間の日時を記録できるシンプルな回数・行動ログアプリです。
Supabaseにログインして使うので、記録はアカウントに紐づいて保存され、複数端末から同じ記録を見られます。

**公開URL**: https://bcno01.github.io/botton-journal/

## 使い方

1. メールアドレスとパスワード(6文字以上)でアカウント登録 / ログイン
2. 上部のフォームに名前を入力して「＋ 追加」すると、その名前のボタンが作られる
3. ボタンの「押す」をタップするたびに、その日時が記録される
4. 「履歴を見る」で、そのボタンの記録一覧(日時つき)を確認・個別削除できる
5. 上部タブの「カレンダー」に切り替えると、月表示でどの日に記録があったか一覧できる。日付をタップすると、その日の全ボタンの記録を確認できる
6. 「削除」でボタンごと削除(履歴も含めて削除される)

複数端末・複数タブで開いていても、記録はリアルタイムで同期されます。

## インストール(PWA)

端末にアプリとしてインストールできます。

- **Safari(Mac/iPhone)**: 共有メニュー →「Dockに追加」/「ホーム画面に追加」
- **Chrome**: アドレスバーのインストールアイコンから追加

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)
- データの保存・認証・リアルタイム同期は [Supabase](https://supabase.com/)(`buttons` / `presses` テーブル)
- Service Workerでアプリ本体をキャッシュ(`sw.js`)
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)
